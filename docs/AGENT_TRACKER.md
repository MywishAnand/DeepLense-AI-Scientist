## Planned Agents

Agents will be added here as they are designed and implemented. The framework supports:

- **Stateless agents** (`DLensBaseAgent`) — for single-turn tasks and sub-agents in deterministic workflows
- **Conversational agents** (`DLensConversationalAgent`) — for multi-turn interactions with session memory
- **E2E orchestration agents** (`AbstractBaseAgent`) — for composing multi-agent workflows with typed I/O
